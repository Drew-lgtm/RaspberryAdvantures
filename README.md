# Plant Watering Statistics Module 📈

This branch houses the MicroPython-optimized `statistics.py` library. It provides lightweight mathematical and statistical functions (such as `mean`, `median`, `mode`, `stdev`, and `variance`) designed for memory-constrained microcontrollers like the Raspberry Pi Pico.

These functions are used by the plant watering sensor code to filter noise from analog ADC sensor readings using a rolling median.
